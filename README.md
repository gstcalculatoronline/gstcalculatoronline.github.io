🧮 GST Calculation Formulas

GST Amount

GST = Original Amount × GST Rate / 100

Amount Including GST

Total = Original Amount + GST Amount

Reverse GST Calculation

Original Amount = Inclusive Amount × 100 / (100 + GST Rate)

CGST and SGST

For intra-state transactions, GST is generally divided equally between CGST and SGST.

For example, 18% GST = 9% CGST + 9% SGST.
