# SEO-Friendly Website Template

This package provides a clean, production-ready website template configured with search engine optimization (SEO) best practices:

- **Semantic HTML5 Elements** (`<header>`, `<main>`, `<footer>`, `<nav>`)
- **Meta Tags**: Unique titles, descriptions, and canonical links for every page.
- **Open Graph Tags**: Optimized for social media sharing and previews.
- **`robots.txt` & `sitemap.xml`**: Pre-configured for search crawler indexing.
- **Performance Focused**: Minimal CSS and lightweight structure to support high Core Web Vitals scores.
